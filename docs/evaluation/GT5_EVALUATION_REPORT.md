# GT-5 Evaluation Report — Golden Dataset, End-to-End

Issue: ORAM15/GroundTruth#33. This report was generated by `python -m groundtruth.evaluation.run_golden` from the raw run output in `docs/evaluation/gt5_run_output.json`, which is committed alongside it; every number below is computed from that file, and a test fails if the two drift apart.

## What was measured, and with what

The golden corpus (4 small documents, listed below) was seeded through the real `POST /api/v1/documents` upload path, and every case was run through the real `POST /api/v1/query` path (hybrid retrieval, dense-evidence abstention gate, grounded generation, citation verification), against a throwaway SQLite database.

**Providers: deterministic evaluation doubles** (embedding: `evaluation-double/bow-eval-v1`, a lexical bag-of-words embedding; generation: `evaluation-double/scripted-top-evidence-v1`, a scripted compliant model that quotes the top evidence block and cites it). No Gemini API key exists in this environment, so these numbers validate the pipeline mechanism — gating, ranking, citation enforcement, scoring — and NOT production behaviour with Gemini embeddings or a real model. See the limitations section; the same harness runs against the real Gemini providers with `--live` and no code changes.

## Limitations

- **Deterministic providers.** The embedding double is lexical (bag-of-words), so questions were written to share vocabulary with their gold chunks; a semantic embedding would score paraphrases differently. The generation double is a scripted compliant model: it always answers from the top evidence block when the gate passes and never refuses on content grounds, so end-to-end correctness here measures retrieval + gating + citation enforcement, not a real model's judgement. Adversarial results therefore demonstrate the structural defences (gate + citation verification), not that a real model cannot be manipulated.
- **Latency is local and in-process** (TestClient against SQLite on the machine that ran the harness). It excludes network, Gemini API and Postgres latency and must not be quoted as production latency.
- **Small, synthetic dataset.** 26 cases over 4 tiny documents with one fact per chunk. Rates have wide uncertainty; the dataset is a regression harness, not a benchmark.
- **Fact containment is a substring check** on the returned answer — crude, mechanical, and stated as such wherever the number is used.
- **Citation validity is enforced by the endpoint by construction** (answers with unverifiable citations are converted to abstentions), so a 100% validity figure confirms the gate works; it is not evidence about model behaviour.

## Reproduce

```bash
# Deterministic doubles (no key needed) — regenerates both files:
python -m groundtruth.evaluation.run_golden

# Live Gemini providers (requires a Gemini API key):
GT5_LIVE=1 GEMINI_API_KEY=... python -m groundtruth.evaluation.run_golden
```
