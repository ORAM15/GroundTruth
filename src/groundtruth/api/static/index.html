    How it works

    1. Upload a PDF — it becomes searchable evidence.
    2. Ask a specific question about what it contains.
    3. You get an answer with citations, or an honest decline when the evidence is not enough.

    Tip: specific questions work best. “What does the report say about X?” beats “tell me everything”.

    GroundTruth answers only from stored evidence and verifies every citation before showing an answer. When the evidence is not enough, it says so — plainly, and without inventing a source.
